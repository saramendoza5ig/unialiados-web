# Cotizador — plantilla para reunión de definición funcional

Esta plantilla sirve para cerrar la definición del cotizador antes de implementar las reglas definitivas.

## 1. Objetivo del cotizador

- ¿Qué desea obtener el usuario al finalizar?
- ¿Es una cotización definitiva, un estimado, un rango o una solicitud para que un asesor cotice?

Preguntas clave:

- ¿Existen tarifas fijas, porcentajes, mínimos o máximos?
- ¿Hay tablas comerciales por servicio, rango, cantidad o tipo de cliente?
- ¿Qué ocurre si una combinación no puede cotizarse automáticamente?
- ¿Los valores incluyen o excluyen impuestos?
- ¿Quién podrá actualizar tarifas a futuro?

## 4. Resultado que verá el usuario

Definir cuál de estas salidas aplica:

- Valor exacto.
- Rango estimado.
- Desglose por conceptos.
- Mensaje sin valor y contacto con asesor.
- Otra salida definida por Unialiados.

También definir textos, disclaimers y vigencia del resultado.

## 5. Acción posterior

- ¿El usuario puede enviar la cotización?
- ¿Debe dejar nombre, correo, teléfono u otros datos?
- ¿Se envía información por correo, WhatsApp o a un asesor?
- ¿Se necesita descargar PDF o resumen?
- ¿Se debe guardar la solicitud en base de datos?
